# 🚀 Smart BMI Calculator | AI Health Assistant

A modern and intelligent **BMI Calculator Application** built using **Python, HTML, CSS, and JavaScript** with advanced features like:

* 🎤 Voice Assistant
* 🤖 AI Health Suggestions
* 📊 BMI Dashboard & Analytics
* 📈 Interactive Graphs
* 🌙 Dark/Light Theme
* ✨ Modern App-like UI

This project was developed as part of my internship task and focuses on creating a real-world health tracking experience instead of a simple calculator.

# ▶️ Running Web Version

Simply open:

```bash
index.html
```

OR use Live Server extension in VS Code.

---

# ▶️ Running Python Version

## Install Required Libraries

```bash
pip install matplotlib pyttsx3 SpeechRecognition pyaudio
```

If PyAudio gives error:

```bash
pip install pipwin
pipwin install pyaudio
```

---

## Run Application

```bash
python bmi_final.py
```
